# Arni Lite 0.1.2

- Settings with live Russian, English and Kazakh interface switching.
- Saved text-preview wrapping, enabled by default.
- About/version information and exportable technical-log ZIP files that exclude credentials, conversations and recordings.
- Native audio/video previews with playback, seeking and volume.
- Optional local dictation using multilingual Whisper base. Download the model and CPU engine in Settings → Dictation (about 150 MB); recording and recognition run locally and insert editable text into the draft without sending it.
- Signed application updates in Settings: automatic startup checks, optional preview releases, verified downloads, saved restart drafts and an explicit Install and restart action.
- Future macOS/Avalonia client tracked in the project tasks. Agent browser/HTML work remains deferred.

## Downloads

- `ArniLiteSetup-0.1.2-x64.exe` for 64-bit Windows.
- `ArniLiteSetup-0.1.2-x86.exe` for 32-bit Windows, also usable on 64-bit Windows.
- .NET Framework 4.8 or newer is required. Installers run per user and retain conversation data.
- `SHA256SUMS-0.1.2.txt` contains installer checksums.
- `update.json` and `update.json.sig` authenticate this release for clients containing the updater. Users of 0.1.1 must install this version manually once.

## Validation and limits

65 automated tests passed on the implemented feature code. Native net48 checks verified the pinned Whisper download, extraction, local transcription through the application's process runner, temporary-file cleanup and update-signature verification. Earlier native media checks covered WAV and MP4 playback/seeking.

Live microphone capture, Russian/Kazakh recognition quality, Windows 7 SP1/Server 2012, older CPUs/32-bit OS, RDP/high DPI and a full installed-client update/restart still need separate acceptance checks. Media decoding depends on available Windows components/codecs. HTML remains a text preview.
