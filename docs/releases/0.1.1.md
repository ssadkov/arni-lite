# Arni Lite 0.1.1

- New native workspace: projects and conversations in one searchable sidebar, selected chat highlighting and collapsible project groups.
- Compact conversation header, optional resizable file panel and local read-only text previews.
- Always-on agent mode, working request cancellation and restoration of each conversation's project folder.
- Account card with email, access type, remaining free steps and applicable paid budgets. Fixed account loading when the server returns `budget: null`.
- Quotas refresh after a turn and can be refreshed manually. Catalog errors no longer hide account information.
- Tool details are collapsed by default. Known OpenRouter free endpoints refused for Arni are excluded; rejected models are not retried on another model automatically.
- Virtualized lists and batched streaming UI updates.

## Downloads

- `ArniLiteSetup-0.1.1-x64.exe` for 64-bit Windows.
- `ArniLiteSetup-0.1.1-x86.exe` for 32-bit Windows, also usable on 64-bit Windows.
- `.NET Framework 4.8` or newer is required.
- Installers run per user. Conversation data remains in `%LOCALAPPDATA%\Arnion\ArniLite`.
- `SHA256SUMS-0.1.1.txt` contains installer checksums.

## Validation and limits

32 automated tests passed before packaging. Both architectures are compiled separately and passed launch, TLS, DPAPI, PowerShell, Cyrillic output and process-stop self-checks. The interface and live account card were checked on this Windows 11 machine. Windows 7 SP1, Windows Server 2012, RDP and high-DPI variants still require separate compatibility testing.

This release does not yet include language switching, audio/video preview or browser automation.
